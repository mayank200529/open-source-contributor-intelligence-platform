# Open Source Contributor Intelligence Platform

## Overview

A data analytics platform that collects and analyzes GitHub contribution data to generate insights on contributor productivity, repository health, pull request activity, and contribution trends.

## Features

* Repository Analytics
* Pull Request Analytics
* Commit Activity Tracking
* Contributor Ranking System
* Repository Health Scoring
* Contribution Heatmap Analytics
* Power BI Dashboards
* Basic Activity Prediction Module

## Tech Stack

* Python
* GitHub REST API
* Pandas
* Power BI

## Analytics Modules

* Repository Analytics
* PR Analytics
* Commit Analytics
* Activity Analytics
* Contributor Insights
* Repository Health Analytics

## Dashboard Pages

1. Contributor Overview
2. Contributor Insights
3. Repository Health & Technology Insights
4. Contribution Analytics
5. Activity Prediction
